Last updated: 2026-10-09 · Applies to the FinalCap web editor at grepawk.com/v2 (preview)

The FinalCap web editor at /v2 edits your videos inside your browser using FFmpeg compiled to WebAssembly (ffmpeg.wasm). The FFmpeg core we send to your browser is built with --enable-gpl and includes libx264 and libx265, so that core is distributed under the GNU General Public License, version 2 or later. We serve these files unmodified from the published npm packages listed below. You can get the complete corresponding source code from the links in this table: each one points to the exact release tag or commit used for that build.
