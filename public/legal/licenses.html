Last updated: 2026-10-09 · Applies to the FinalCap web editor at grepawk.com/v2 (preview)

The FinalCap web editor at /v2 edits your videos inside your browser using FFmpeg compiled to WebAssembly (ffmpeg.wasm). The FFmpeg core we send to your browser (@ffmpeg/core and @ffmpeg/core-mt 0.12.10, served unmodified from /v2/ffmpeg-core/) is built with --enable-gpl and includes libx264 and libx265, so it is distributed under the GNU General Public License, version 2 or later.

Source code

The complete corresponding source code for that core is available from this website, next to the WebAssembly files, at /v2/vendor/ffmpeg/source/. It includes:

  • the ffmpeg.wasm build recipe at the exact release commit of core 0.12.10 (ffmpegwasm/ffmpeg.wasm@71aa99d3, tag v12.15: Dockerfile, Makefile, build/*.sh, bindings and patched fftools), and build instructions;
  • the exact source archive of FFmpeg 5.1.4, x264 and every other library compiled into the core, at the tag or commit the build uses;
  • SHA-256 checksums for every archive, and a machine-readable version list;
  • the license texts shipped in each source archive (linked in the table below).
